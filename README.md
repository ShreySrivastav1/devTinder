# 🚀 devTinder – Full Stack Social Matching App

A full-stack social matching application inspired by Tinder, where users can connect and chat in real-time.

---

## 🌐 Live Demo
> Works best when opened directly in browser (HTTP deployment)

http://13.200.233.99/

---

## 🧠 Features

- 🔐 JWT-based authentication using HTTP-only cookies  
- 👤 User profile creation and editing   
- 🤝 Connection request system (interested, ignored, accepted, rejected)  
- 💬 Real-time chat using Socket.io  
- 📄 Pagination support for scalable data loading  

---

## 🛠️ Tech Stack

### Backend
- Node.js  
- Express.js  
- MongoDB + Mongoose  
- JWT Authentication  

### Frontend
- React.js  
- Redux Toolkit  
- Tailwind CSS + DaisyUI  

### Deployment
- AWS EC2  
- Nginx (Reverse Proxy)  
- PM2 (Process Manager)
